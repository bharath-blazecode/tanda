# Kachka evidence ledger

Prepared 22 November 2026 (Australia/Brisbane) on branch `claude/awesome-einstein-e124bb`. One row per
claim the product makes or implies, matched to what the code actually does, not to the topic in general.

## Access levels used here

| Level | Meaning |
|---|---|
| **code** | Read in this repository. Says what the app does, nothing about the world |
| **full text read** | The source document itself was read this session |
| **official guidance (tool)** | An official page read this session through a third-party fetch tool, because direct access is blocked here. Needs the owner to confirm directly |
| **official documentation** | Technical documentation read this session from an allowed host |
| **repository citation** | Recorded in `DECISIONS.md` during the hackathon. Not retrieved this session. Not verified research |
| **blocked** | Retrieval was attempted this session and refused. The claim is narrowed or held back |

Entries marked "repository citation" carry the population and protocol as `DECISIONS.md` recorded
them. Those details are claims about the source, not checked facts, until someone reads the source.
