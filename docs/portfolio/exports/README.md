# PDF export

[Kachka-Astra-Ultra-Handoff.pdf](Kachka-Astra-Ultra-Handoff.pdf) is the formatted reading copy of the portfolio handoff. It contains the research brief, the complete Astra Ultra implementation prompt and a source-status index with clickable links.

The editable sources are [RESEARCH-BRIEF.md](../RESEARCH-BRIEF.md), [ASTRA-ULTRA-PROMPT.md](../ASTRA-ULTRA-PROMPT.md) and [SOURCES.json](../research/SOURCES.json). The longer current-state, evidence and security memos are linked from the [handoff guide](../README.md).

The PDF was generated with ReportLab using embedded DejaVu fonts on A4 pages. It has a linked contents list, bookmarks, selectable text, repeating table headers and page numbers. The green cover and restrained table styling reflect the app's existing instrument palette.

Validation checked all 18 pages for extractable text and required sections, and visually inspected the cover, contents, a claims table, the prompt and the source index. This is layout verification, not PDF accessibility certification or validation of the scientific claims.

Refresh the PDF whenever the Markdown or source statuses change. Preserve the difference between retrieved technical documents, blocked health sources and citations that have not been retrieved. Do not remove access qualifications to make the export appear more complete.
